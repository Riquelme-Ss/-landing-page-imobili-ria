# Imobiliária Luciana Farias - Landing Page

Landing page desenvolvida para corretagem de imóveis na região de Pernambuco. O site é focado em alta conversão, separando o público do programa Minha Casa Minha Vida (Caixa) de clientes que buscam Casas Soltas.

## 🚀 Tecnologias Utilizadas
- **HTML5**
- **Tailwind CSS** (via CDN)
- **JavaScript** (Vanilla)
- **FontAwesome** (Ícones)

## ⚙️ Funcionalidades
- **Filtro Cruzado Dinâmico:** Filtragem de imóveis por Categoria e Cidade em tempo real usando JavaScript puro.
- **Carrossel de Imóveis:** Galeria de fotos customizada em formato modal.
- **Captação de Leads via WhatsApp:** Formulário que envia os dados do cliente e o interesse diretamente para o WhatsApp da corretora.
- **Design Moderno e Responsivo:** UI com efeito Glassmorphism (vidro) no cabeçalho e Hero section, 100% adaptado para dispositivos móveis.
